Why this exists

Last semester, three professors pulled me aside. "This essay is too good." "Did you use AI?" "The structure is suspicious."

I didn't. I just write well when I care about the topic. But there's no way to prove that. Turnitin checks if you copied someone else. GPTZero guesses based on word patterns. Neither proves you sat down and typed it.

The problem isn't AI. The problem is we lost the ability to prove human effort.

So I learned Python in Termux on my phone. Switched to a slow laptop. Built a classifier that looks at keystrokes — not words. Dwell time. Flight time. Backspaces. Pauses. The messy, inconsistent rhythm of a human thinking.

When I type naturally: ✓ 75% human score. When I paste ChatGPT output: ✗ 5% human score.

It works. Not perfectly. But honestly.

How it actually works

1
⌨️

User types in your form

We capture keystroke dynamics in the browser. Key-down, key-up, timestamps. Not the content — the rhythm. No keyloggers. No screenshots. Just timing data that stays in the browser until they hit verify.

2
🧠

Backend analyzes behavior

FastAPI server extracts features: dwell time (how long keys are held), flight time (gaps between keys), error rate, rhythm consistency. Feeds into a classifier trained on real typing patterns — not text analysis.

3
⛓️

Proof hash gets anchored

SHA-256 hash of the session data. Timestamped. Blockchain-anchored on Polygon testnet (mainnet later). Tamper-proof. Publicly verifiable forever. You can dispute it in court if you need to.

4
✅

Badge appears

"Verified Human" or "Unverified." Companies decide what to do with it. Block submission? Flag for review? Let through? Their call. We just provide the signal. No black boxes. No "trust us" — the proof is public.

Add it to your site in 5 lines

No npm install. No build step. No framework lock-in. Drop this in any HTML form and it just works.

index.html 
<!-- Load the SDK from our server -->
<script src="https://prooflayer-production-bc8a.up.railway.app/static/prooflayer-sdk.js"></script>

<script>
// Initialize with your API key
const proof = new ProofLayer({
    apiUrl: 'https://prooflayer-production-bc8a.up.railway.app',
    apiKey: 'your-key-here',
    onVerify: function(result) {
        if (result.is_human > 0.7) {
            document.getElementById('submit').disabled = false;
        }
    }
});

// Watch any input field
proof.observe(document.getElementById('essayInput'));
</script>
